# КурьерРадар — плавающий виджет «сколько реально заработаю»

Android-приложение для курьеров Яндекс Про (и любых других курьерских приложений).
Как только ты открываешь приложение курьера, поверх него появляется плавающий виджет:
он читает карточку заказа, вычитает твои расходы и показывает **чистую сумму, ₽/км и ₽/час**
до того, как ты нажмёшь «Принять». Дешёвые заказы помечаются красным и вибрируют.

> Честно о главном: приложение **не взламывает** чужой клиент и не меняет сумму заказа.
> Оно берёт то, что уже видно на экране карточки (сумма, километры, минуты), и считает
> по твоим настройкам расходов настоящую ставку. Именно этого обычно не хватает, чтобы
> не брать заказы «300 ₽ / 12 км».

---

## Что умеет

- **Плавающий виджет поверх Яндекс Про.** Появляется при запуске приложения курьера,
  исчезает, когда ты выходишь. Круглый «пузырь» можно перетащить в любое место экрана,
  тап — раскрыть карточку, долгое нажатие — скрыть до следующего запуска.
- **Автоматическое чтение карточки заказа** через службу спец. возможностей:
  сумма ₽, километры, минуты. Ничего не надо вводить руками.
- **Честная математика:**
  `чистыми = выплата − комиссия − топливо − амортизация`,
  считается с учётом обратного пути (опция), затем `₽/км` и `₽/час` чистыми.
- **Вердикт светофором:** `БРАТЬ` (зелёный) / `НА ГРАНИ` (жёлтый) / `СКИП` (красный)
  по твоим порогам. Показывает, во сколько раз заказ лучше или хуже порога.
- **Вибросигнал** на невыгодный заказ — чтобы не пропустить, когда смотришь в телефон.
- **Ручной калькулятор** в самом приложении: сумма / км / мин → ставка и вердикт.
- **Статистика** за день и за всё время: сколько взял, сколько скипнул, чистыми, средний ₽/км.
- **Ноль сети.** Нет разрешения INTERNET: данные не уходят никуда, всё живёт в телефоне.

## Установка (APK)

**Самый простой путь — готовый APK из релиза:**

https://github.com/AlfaGideon/YandexFinance/releases/latest

1. Открой ссылку **с телефона** и скачай `app-debug.apk`.
2. Разреши установку из неизвестных источников и установи.
3. Открой «КурьерРадар» и выдай разрешения (см. ниже), включи тумблер «Радар включён».

**Свежая сборка из исходников:** вкладка **Actions** → workflow **Build APK** → последний
успешный запуск → артефакт `courierradar-apk`. Каждый релиз `v1.0.N` собирается автоматически.

### Сборка вручную

```bash
# нужен JDK 17 и Android SDK 34
gradle assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
```

В Android Studio: `File → Open` → выбрать папку проекта → Run. Если студия ругается
на отсутствие wrapper — `gradle wrapper --gradle-version 8.7`, затем `./gradlew assembleDebug`.

## Разрешения и зачем они

| Разрешение | Зачем | Обязательно |
|---|---|---|
| **Поверх других приложений** (`SYSTEM_ALERT_WINDOW`) | собственно плавающий виджет | да |
| **Спец. возможности** (`AccessibilityService`) | прочитать текст карточки заказа и понять, что открыт Яндекс Про | да, для автоподстановки суммы |
| **Доступ к данным об использовании** (`PACKAGE_USAGE_STATS`) | резервный способ понять, что запущено приложение курьера | нет, но полезно |
| **Уведомления** (Android 13+) | постоянное уведомление foreground-сервиса | нет |
| **Автозапуск после перезагрузки** | виджет поднимается сам | нет |

Приложение не требует интернет-доступа, не читает SMS/контакты/файлы, не шлёт ничего наружу.

## Если виджет не появляется

Порядок проверки — сверху вниз, 99% случаев закрываются первым пунктом.

1. **Android 13+ блокирует спец. возможности для APK «не из маркета».**
   В настройках спец. возможностей напротив приложения написано «Ограниченные настройки»
   и переключатель серый. Лечится так:
   `Настройки → Приложения → КурьерРадар → меню «⋮» (три точки справа сверху) →
   «Разрешить ограниченные настройки»` → подтвердить PIN/отпечаток → вернуться в
   `Настройки → Специальные возможности → КурьерРадар` и включить.
   На Samsung: `Настройки → Приложения → ⋮ → Специальный доступ → Особые возможности`,
   на Xiaomi: `Настройки → Приложения → КурьерРадар → ⋮ → Разрешить ограниченные настройки`.

2. **Открой нужное приложение и нажми «+ Пакет»** в блоке «Диагностика» — оно попадёт в
   список. Если пакет называется `ru.yandex.taximeter` (Яндекс Про/таксометр) — он уже
   в списке по умолчанию, а режим «Любое приложение Яндекса» ловит вообще все `ru.yandex.*`.

3. **Посмотри «ДИАГНОСТИКУ» на главном экране.** Она живая и показывает:
   включены ли спец. возможности и **работает ли служба**, включён ли сервис, какое
   приложение сейчас на экране и распозналась ли последняя карточка заказа.
   — «служба не подключена» → перезагрузи телефон.
   — приложение на экране не помечено `✓ в списке` → `Настройки расчёта →
   «Найти приложения Яндекса»` и отметь свой клиент.

4. **Кнопка «Показать виджет»** в блоке «Диагностика» — принудительно выводит кружок
   на экран. Если кружок появился, значит проблема только в определении приложения:
   включи в настройках **«Показывать виджет всегда»**.

5. **Энергосбережение.** MIUI/EMUI/OneUI/Oppo часто убивают foreground-сервис:
   `Настройки → Приложения → КурьерРадар → Батарея → «Без ограничений»` и разреши
   **автозапуск**. Проверь, что приложение не в списке «спящих».

6. После переустановки APK все разрешения (оверлей + спец. возможности) нужно выдать заново.

## Разрешение слетает, когда чистишь фоновые процессы

Это не баг приложения: «Очистить всё» на многих прошивках делает **force-stop** приложений,
а Android по правилам **снимает** спец. возможности у приложения, которое принудительно
остановили. Вернуть себе разрешение программа сама по себе не может — но есть два пути.

### Путь 1. Сделать так, чтобы процесс не убивали (без компьютера)

- `Настройки → Приложения → КурьерРадар → Батарея → «Без ограничений»`
  (в приложении есть кнопка **«Работа в фоне»** — она открывает нужный диалог).
- Разреши **автозапуск**: MIUI — «Автозапуск», EMUI — «Управление запуском»,
  ColorOS — «Автозапуск приложений», OneUI — «Батарея → Ограничения».
- На Xiaomi **заблокируй карточку приложения** в списке недавних задач (длинный тап →
  замок): тогда «Очистить всё» её не тронет.
- Лучше не жать «Очистить всё», а смахивать по одному приложению.

### Путь 2. Автовосстановление (одна ADB-команда, работает даже после очистки)

Приложение умеет **само возвращать** разрешение через ~7 секунд после того, как Android его
снял, — но для этого нужен доступ к защищённым настройкам. Одна команда, один раз:

```bash
adb shell pm grant ru.courierradar android.permission.WRITE_SECURE_SETTINGS
```

Включи отладку по USB (`Настройки → О телефоне → 7 раз по «Номер сборки» →
Для разработчиков → Отладка по USB`), подключи телефон к компьютеру и выполни команду.

Без компьютера: поставь **Shizuku** (запускается через беспроводную отладку) и любой
ADB-терминал, например Termux + `pkg install android-tools`, затем ту же команду.

После выдачи права в приложении появится строка
`✓ Автовосстановление спец. возможностей: включено`, а кнопка **«Автовосстановление»**
будет возвращать службу по нажатию. Дальше всё происходит само: служба-сторож раз в 7 секунд
проверяет состояние и, если разрешение слетело, ставит его обратно.

> Что останется работать, если разрешение всё же слетит: плавающий виджет продолжит
> появляться (он опирается на «Доступ к данным об использовании»), но сумму из карточки
> читать будет нечем — считай в калькуляторе, пока не вернёшь спец. возможности.
> Если и это не нужно — включи «Показывать виджет всегда».

## Как пользоваться

1. Включи тумблер «Радар включён».
2. Выдай разрешения, которые подсвечены `—`.
3. Открой Яндекс Про и дождись карточки заказа. В виджете появятся сумма, ₽/км, ₽/час.
4. Не согласен с расчётом — нажми «Счёт», поправь сумму/км/мин и посчитай вручную.
5. Кнопки «Взял» / «Скип» пишут заказ в статистику.

## Настройка под себя (`Настройки расчёта`)

- **Пороги** — минимум `₽/км` и `₽/час` чистыми. Поставь свои: например 25 ₽/км и 450 ₽/час.
  Всё, что ниже — красное.
- **Расход топлива** л/100 км, **цена литра**, **амортизация ₽/км** (масло, шины, ТО, мойка).
  Пеший курьер ставит нули.
- **Комиссия сервиса, %** — если у тебя схема с удержанием.
- **Обратный путь ×2** — включай, если едешь за город и возвращаешься порожняком.
- **Пакеты приложений** — под какими приложениями показывать виджет. По умолчанию в списке
  есть `ru.yandex.taximeter`, `ru.yandex.taximeter.beta` (это и есть «Яндекс Про»), а также
  `ru.yandex.taxi`, `ru.yandex.ytaxi`, `ru.yandex.taxi.courier`, `ru.yandex.taxi.driver`,
  `ru.yandex.pro`, `ru.yandex.lavka.courier`, `com.yandex.courier`, `ru.yandex.go.courier`.
  Плюс включён режим **«Любое приложение Яндекса»**: виджет появляется над любым пакетом
  `ru.yandex.*` / `com.yandex.*`, так что переименование пакета в новой версии клиента
  ничего не ломает. В настройках есть кнопка **«Найти приложения Яндекса на телефоне»**
  (галочки по установленным приложениям) и кнопка **«+ Пакет»** в диагностике — она
  добавляет в список то приложение, которое сейчас открыто.

## Ограничения (важно)

- **Сумма читается с экрана, а не из API.** Яндекс регулярно меняет вёрстку карточки:
  если сумма не распозналась — виджет покажет `—`, а километры/минуты можно ввести в калькуляторе.
  Скриншоты разных версий карточки в студию: парсер поправим.
- **Чаевые и бонусы** заранее неизвестны, поэтому в расчёт не входят — они идут сверху.
- **Приложение не показывает «скрытую» сумму сервиса.** Оно считает из той суммы, которую
  показывает карточка, минус твои реальные расходы. Это и есть «конечная сумма за заказ»,
  которую ты кладёшь в карман.
- Оверлей может конфликтовать с некоторыми «оптимизаторами» батареи — добавь приложение
  в исключения, если виджет пропадает.
- Чтение экрана — это чувствительное разрешение. Приложение работает локально и ничего
  не передаёт, но помни, что правила сервисов могут ограничивать сторонние оверлеи:
  решай сам, использовать ли его во время смены.

## Приватность

Нет `INTERNET`, нет аналитики, нет аккаунтов. Текст карточки обрабатывается в памяти,
сохраняются только агрегаты по твоим заказам (в SharedPreferences телефона).
